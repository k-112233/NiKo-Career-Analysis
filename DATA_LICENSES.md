# Third-party data attribution

Code and third-party data are separate works. This file does not assert ownership of source observations.

- **Filipe Macedo — Counter Strike Competitive Data**, version 1: https://www.kaggle.com/datasets/filipechavesdemacedo/counter-strike-competitive-data . Source metadata declares **CC BY 4.0**: https://creativecommons.org/licenses/by/4.0/ . Changes: filtered player 3741, normalized into a project schema, joined with match dimensions, computed descriptive summaries. Original file hashes are recorded in `data/provenance/sources.json`.
- **Maxim (ektarr) — Counter-Strike Pro Matches**, version 10: https://www.kaggle.com/datasets/ektarr/counter-strike-pro-matches . Source metadata declares **CC BY-SA 4.0**: https://creativecommons.org/licenses/by-sa/4.0/ . The processed derivative `data/processed/niko_ektarr_cs2_v10.csv` is distributed under that license. Changes: filtered provider player 26 by full name/country, removed series totals, normalized fields, preserved provider IDs, and reconciled observations against independent history excerpts. The derivative source layer incorporated into `niko_maps.csv` retains these attribution and share-alike terms; other layers retain their own terms. Retain this notice with data and redistributed adaptations.
- **tedtay — CS:GO Pro Matches Comprehensive Dataset**: https://github.com/tedtay/CS-GO-Pro-Matches-Comprehensive-Dataset . The README declares distribution under the MIT License. Its original notice is preserved at `data/provenance/tedtay_LICENSE.txt`. Changes: inherited name/team/date-filtered 157-map derivative. The license file contains the README-template author's name; this notice reproduces it rather than substituting a guessed author.
- **HLTV.org — NiKo player history**, player ID 3741: https://www.hltv.org/stats/players/matches/3741/niko . Factual observations from readable public history results, collected 2026-11-10, with retained source URLs. No separate open-data license was verified and this project does not grant an invented one. HTML, logos, photos and article text are not bundled.

Processed factual snapshots, source observations and generated reports must retain the relevant source attribution. The release is a partial-data research portfolio, not an official HLTV or team product. Source metadata and transformations are documented in docs/sources.md.
