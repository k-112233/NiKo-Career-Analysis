# Changelog

## 1.0.0 — 2026-11-10

First portfolio release. Scope: reproducible descriptive analysis of a fixed, partially covered NiKo career snapshot.

- 2,030 accepted map observations, including 195 G2 CS2 and 381 Falcons maps.
- Career stages, same-source CS2 combat comparison, map profiles and win/loss associations.
- Offline dashboard with team, game version, rating methodology, date and minimum-sample filters; CSV export.
- Source identity audit, original archive SHA-256 verification, 231 cross-source Rating joins and explicit conflict quarantine.
- Report, three analysis notebooks, data dictionary, source attribution, CI and release archive verification.

Known limits: sparse 2021–2023 coverage, missing 2023 transition records and other source omissions. No opponent-rank, stage, weapon or causal transfer-effect claims. Missing Rating remains missing. See `docs/sources.md`.
